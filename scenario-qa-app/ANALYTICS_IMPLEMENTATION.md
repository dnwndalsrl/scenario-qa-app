# 프로젝트 품질 분석 대시보드 구현 보고서

## 1. 구현 범위

개별 실행, 비교, 스위트, 예약 실행, 알림 전달을 읽기 전용으로 집계하는 API 8개와 `/projects/[projectId]/dashboard` 화면을 구현했다.

## 2. 기존 구조

기존 JSON 저장소·repository·service·Nuxt API 응답 래퍼를 유지했다. 실행 상세는 `TestRunService.getDetail()`로 결과 JSON을 읽으며 저장 원본을 수정하지 않는다.

## 3. 추가 패키지

추가 패키지는 없다. 기존 Luxon, Zod, Vitest, Element Plus만 사용했다.

## 4. 환경 변수

`.env.example`에 버전, 기본/최대 기간, 캐시 TTL, 차트 점 수, 목록 제한, 최소 표본, 품질 임계값, 선택적 AI 설정을 추가했다.

## 5. 폴더 구조

서버 코드는 `server/analytics/{services,utils}`, 검증은 `server/validators`, 공용 타입은 `shared/types/analytics.ts`, UI는 `components/analytics`와 대시보드 페이지에 배치했다.

## 6. 타입

기간·필터·지표·비교·품질 상태·시계열·시나리오·단계·스위트·예약·오류·최근 문제 응답을 명시적으로 타입화했다. 값 없음은 `null`, 실제 0은 `0`으로 직렬화한다.

## 7. 날짜 범위

로컬 날짜를 요청 시간대의 하루 경계로 해석한 후 UTC로 바꾼다. 직전 기간은 현재 기간과 밀리초 길이가 같고 최대 조회 기간은 730일이다.

## 8. 비율과 백분위

분모가 0이면 비율은 `null`이다. 평균, 중앙값, 최솟값, 최댓값, 선형 보간 P95를 계산한다.

## 9. 지표 방향

모든 비교는 현재값, 이전값, 절대 차이, 변화율, 유리한 방향, improved/degraded/unchanged/not_comparable 판정을 제공한다.

## 10. 버킷

1일 이하는 시간, 90일 이하는 일, 365일 이하는 주, 그 이상은 월 단위다. 빈 구간도 생성하며 400점을 초과하는 명시적 단위는 거부한다.

## 11. 테스트 실행 집계

pending/running을 제외하고 success/failed/blocked/error만 센다. 전체 단계 성공률과 blocked를 제외한 실행 단계 성공률을 따로 계산한다.

## 12. 회귀 집계

완료 비교만 분모로 사용한다. 비교가 없는 실행은 회귀율 분모에 포함하지 않으며 회귀·해결·지속 실패와 단계 회귀율을 제공한다.

## 13. 스위트 집계

완료 상태만 집계하고 순수 성공률과 success+partial_success 허용률을 구분한다. 실행 당시 스냅샷 이름을 우선한다.

## 14. 예약 집계

감지·완료·건너뜀·실패·스위트 생성·동시성/미실행 건너뜀·감지/시작 지연·알림 성공/실패를 집계한다.

## 15. 오류 집계

실행·단계·콘솔·네트워크 오류를 종류별로 정규화하고 SHA-256 기반 짧은 fingerprint로 묶는다. URL, 경로, UUID, 긴 숫자는 마스킹한다.

## 16. 시나리오와 단계

시나리오별 실행 수·성공률·회귀율·평균 시간·최근 상태와 실패 단계별 횟수·영향 실행·오류 표본을 제공한다.

## 17. 최근 문제

실행 실패, 회귀, 스위트 실패, 예약 실패/건너뜀, 알림 실패를 시간 역순으로 합치고 기존 상세 화면 링크를 제공한다.

## 18. 캐시

프로젝트, 기간, 시간대, 필터, 버전, endpoint를 정렬된 키로 묶어 60초 메모리 캐시에 저장한다. 반환 시 복제해 캐시 값 변조를 막는다.

## 19. API

`summary`, `timeseries`, `scenarios`, `suites`, `schedules`, `failing-steps`, `errors`, `recent-issues` GET API를 구현했다.

## 20. 기간 필터

오늘, 최근 7/30/90일, 이번 달, 지난 달, 직접 설정과 시간대·트리거·시나리오·스위트·예약·환경 필터를 제공한다.

## 21. 요약 카드

완료 실행, 성공, 실패·차단, 오류, 회귀, 평균 시간, 스위트 성공률, 예약 완료율과 직전 기간 비교를 표시한다.

## 22. 품질 상태

AI 없이 최소 표본과 성공률·회귀율·오류율 임계값으로 healthy/warning/danger/insufficient를 결정하고 이유를 표시한다.

## 23. 성공 차트

버킷별 성공·실패·오류 수를 반응형 막대로 표시하며 범례와 접근 가능한 데이터 표를 제공한다.

## 24. 회귀 차트

회귀·해결·지속 실패 추이를 표시한다. 버킷 선택 시 해당 구간을 직접 설정 기간으로 적용한다.

## 25. 시간 차트

개별 실행 평균·중앙값·P95와 스위트 평균을 같은 시간축에 표시한다.

## 26. 오류 차트

콘솔, 네트워크, HTTP 4xx, HTTP 5xx, timeout 건수를 분리한다.

## 27. 시나리오 표

실행 수, 성공률, 회귀율, 평균 시간, 최근 상태를 표시한다. 고아 기록은 snapshot 이름과 삭제됨 표식으로 유지한다.

## 28. 실패 단계 표

단계명·action·시나리오·실패 수·영향 실행·정규화 오류를 표시하고 최근 실행 상세로 이동한다.

## 29. 스위트와 예약 표

스위트 성공/허용률과 예약 완료율·건너뜀·실패·시작 지연·알림 실패를 별도 표로 제공한다.

## 30. 최근 문제 UI

문제 유형, 심각도, 제목, 정규화 설명, 발생 시각, 상세 링크를 표시하고 문제가 없을 때 별도 빈 상태를 보여준다.

## 31. 선택적 AI

환경 변수 자리만 제공하고 서술 요약 호출은 비활성화했다. 핵심 숫자와 품질 상태는 항상 결정적 집계 결과만 사용한다.

## 32. 오류 코드

프로젝트 없음, 날짜/시간대/버킷/쿼리 오류, 데이터/집계/캐시/내보내기 오류, 선택적 AI 오류 코드를 상수로 정의했다. 현재 구현 API는 관련되는 검증 코드를 반환한다.

## 33. 단위 테스트

비율의 null/0 구분, P50/P95, 시간대 변환, 동일 길이 이전 기간, 자동 버킷, 지표 방향, 캐시 TTL/복제, 품질 상태를 검증한다.

## 34. 통합 테스트

쿼리 정규화 테스트와 실제 프로덕션 서버에서 프로젝트 데이터로 API 8개의 HTTP 200 응답을 확인했다. 과대 기간은 `DATE_RANGE_TOO_LARGE`로 거부됨을 확인했다.

## 35. 실행 방법

`npm run dev` 후 로그인하고 프로젝트의 품질 대시보드 탭을 연다. 직접 주소는 `/projects/{projectId}/dashboard`다.

## 36. 검증 결과

`npm run typecheck`, Vitest 38개 파일 129개 테스트, `npm run build`가 통과했다. 실제 API 결과에서 완료 실행 9건과 시계열 34점 등 저장 데이터 집계도 확인했다.

## 37. 제한 사항

메모리 캐시는 프로세스별이며 재시작 시 초기화된다. CSV 내보내기·AI 서술 요약·품질 점수는 선택 기능이라 구현하지 않았다. 기존 삭제 로직이 이미 제거한 과거 실행은 복구할 수 없지만 남아 있는 고아/snapshot 기록은 정상 집계한다.

## 38. 다음 단계

데이터 증가 시 결과 상세 일괄 읽기를 인덱스/사전 집계로 교체하고, 캐시 명시 무효화와 선택적 CSV·AI 요약을 추가할 수 있다.
