# 무료 플랜과 비용 안전장치

- Vercel Hobby는 개인·비상업 용도에 맞습니다. 상업 운영 전에는 플랜 조건을 다시 확인하세요.
- GitHub 호스팅 표준 실행기는 공개 저장소에서 무료이고, 비공개 저장소는 계정별 포함 시간이 있습니다. 결제 수단이 없으면 포함량 소진 후 작업이 중단되는 방식이지만 계정 정책은 배포 전에 직접 확인하세요.
- Supabase Free는 데이터베이스·스토리지·송신량·월간 활성 사용자 제한이 있고 비활성 프로젝트가 일시 중지될 수 있습니다.
- OpenAI API는 별도 유료 사용량입니다. 이 프로젝트는 페이지 5, 깊이 2, 생성/자동 실행 8, 전체 동시 실행 1, 10분 timeout으로 사용량을 제한합니다.
- GitHub artifact 보존은 3일이며, 장기 결과는 Supabase private Storage에만 둡니다.

완전한 무과금 보장은 각 공급자의 계정 설정과 향후 정책에 좌우됩니다. 예산 알림, 지출 한도, 결제 수단 상태를 각 대시보드에서 확인하세요.
